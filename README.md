📚 Jalawe Learning Hub

Learn. Grow. Anywhere.

Jalawe Learning Hub is an AI-powered mobile learning platform designed to make quality secondary school education accessible to every student in Malawi. The platform provides interactive lessons, quizzes, examinations, AI learning support, and offline learning capabilities to help students study anytime, anywhere.

---

🌟 Features

- 📖 Digital lessons for Forms 1–4
- 🤖 AI Learning Assistant for answering educational questions
- 📝 Topic quizzes with instant feedback
- ⏱️ Timed examinations
- 📚 Past papers and revision materials
- 🔍 Search subjects and lessons
- 📥 Offline learning through downloadable content
- 👤 Student profiles and progress tracking
- 🌐 Responsive design for mobile and web

---

🎯 Problem

Many students have limited access to quality educational resources, internet connectivity, and personalized academic support. This affects learning outcomes and exam performance.

---

💡 Solution

Jalawe Learning Hub provides a centralized learning platform where students can access curriculum-based lessons, practice questions, examinations, and AI-powered academic assistance, even with limited internet access.
